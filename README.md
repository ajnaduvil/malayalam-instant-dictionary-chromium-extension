# Malayalam Instant Dictionary

**Malayalam Instant Dictionary** is a Chromium extension that provides instant English-to-Malayalam translations. Simply double-click any English word on a webpage, and a pop-up will display its Malayalam meaning.

## Features

- Instant English-to-Malayalam translations by double clicking on any word on any site
- Easy-to-use interface with no additional setup required.
- Works seamlessly on any Chromium-based browser.

## Installation

You can install the extension from the following stores:

- [**Chrome Web Store**](https://chromewebstore.google.com/detail/malayalam-instant-diction/aoablanmkdmgfabgbejljmlhpnedmpci)
- [**Microsoft Edge Add-ons Store**](https://microsoftedge.microsoft.com/addons/detail/malayalam-instant-diction/keegdlhklgpeeibhbeklehjdgpmgeame) *(Replace with the actual Edge link if different)*

## How to Use

1. Install the extension from the Chrome Web Store or Edge Add-ons Store.
2. Navigate to any webpage with English text.
3. Double-click on any English word to see its Malayalam meaning in a pop-up.
